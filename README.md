# PSN Game Catalog

個人的 PlayStation 遊戲庫，基於 [promise82114/ps-game-base](https://github.com/promise82114/ps-game-base) 延伸。

## 使用線上版

[開啟 PSN Game Catalog](https://chiarubi-728.github.io/PSN_Game_Catalog/)

[應用程式介紹](https://chiarubi-728.github.io/PSN_Game_Catalog/about.html) · [隱私權政策](https://chiarubi-728.github.io/PSN_Game_Catalog/privacy.html) · [服務說明](https://chiarubi-728.github.io/PSN_Game_Catalog/terms.html)

1. 從「資料管理 → 首次設定／更新腳本」安裝「PSN Game Catalog」整合腳本 **v0.3.8**，並停用舊的「PS Game Base 遊戲庫」及獨立 PSNProfiles／獎盃助手腳本。更新後重新整理本網站及來源分頁。
2. 首次同步先設定自己的 **PSN Online ID**；已有舊數位庫時，需確認資料屬於該帳號。Google 帳號只用於雲端保存，不會代替 PSN 帳號。
3. 平常按 **同步遊戲庫**。Sony 分頁會帶入預期的 PSN 帳號；核對登入帳號並勾選後讀取數位授權。保存完成，由來源分頁自行接續 PSNProfiles 全部遊玩／獎盃紀錄，最後補齊官方中英文名稱並合併。
4. Sony 登入與 PSNProfiles 網站驗證需在來源分頁完成。各階段顯示進度，中途失敗保留已保存的部分，可重試未完成步驟。Sony 帳號確認由使用者核對，腳本不會自動驗證登入身分。

所有日常功能都在瀏覽器完成，不需要安裝 Node、啟動本機助手或轉移本機名稱資料。首次若已有完整備份，可從資料管理匯入；網站原有存檔沿用。

## 遊戲庫

- 合併數位擁有與所有遊玩紀錄，包含數位庫沒有的遊戲。
- PS4／PS5 分開；白金和 100% 完成分別判定。
- 跨平台卡片依已確認的名稱對照優先統一顯示中文名稱，例如「天命2 · PS4／PS5」；英文名稱仍可搜尋，授權、進度與獎盃各自保留。
- 已確認的系列名支援中英文互搜，例如「戰地／Battlefield」；Battlefield V 與戰地風雲 5 也有名稱對照。商品 ID 已確認的現行名稱優先於舊遊戲庫標籤。
- 保留側欄分類導航，清單預設依名稱排列；獨立搜尋欄可依中英文名稱及已保存別名搜尋目前分類。
- 首頁使用緊湊摘要：總數／尚未整理、白金／追蹤／忽略；白金統計仍依來源獎盃計算，追蹤改用綠色。數位擁有與遊玩紀錄數量以輔助文字顯示，統計只出現在「所有遊戲」。
- 搜尋旁提供 PS5／PS4／PS3／PS Vita 及白金／忽略／追蹤三段式標籤（選取 → 排除 → 取消），自訂分類維持下拉複選。同組選取取聯集、排除優先，各組取交集；完成率範圍與搜尋共同生效。搜尋欄內 × 清除，不再插入清除平台／分類按鈕。
- 可依取得／領取、最後獲得獎盃時間排序，支援新到舊／舊到新。日期缺漏永遠排最後，主頁隱藏長說明與無日期文字；取得日期讀不到時改用 Sony 取得先後順序，缺順序的排最後。取得日期不等於付款日期。新日期須更新 v0.3.8 腳本後重新同步，來源未提供則留空。
- 金色 PS Plus 圖示依數位授權來源顯示於卡片及側欄；歷史授權另外標示，不推定目前訂閱或遊玩權限。
- 卡片隱藏其他語言名稱，完整別名仍可搜尋；白金固定左下角，PS Plus 固定右下角。追蹤／忽略留在右上角，資料夾選單可直接加入或新增自訂分類。快捷整理立即儲存，卡片暫留當頁，切換頁面或篩選後重新計算。
- 個人分類、標籤、筆記與手動白金標記保留；已取得白金統計依來源 ID 去重。
- 補齊名稱而重新配對時，沿用來源卡片的個人整理；獨立狀態衝突先保留忽略，舊筆記可在編輯視窗查看。白金清單也包含個人白金標記。
- 切換搜尋、側欄或篩選條件會清除勾選；自訂分類與其他篩選共同取交集。儲存失敗時保留編輯內容，讀檔失敗時鎖定寫入並提供原始存檔匯出與完整備份復原。
- 標記「忽略」的遊戲平常只在「忽略」清單顯示；明確勾選上方「忽略」篩選時，可與目前側欄、平台、自訂分類等條件取交集。解除忽略後恢復依原資料分類。
- 資料先存於目前瀏覽器，可設定 Google Drive 自動同步（試用）。網站已提供共用的公開 OAuth Client ID，直接按 Google 登入；換裝置登入同一 Google 帳號。自架網站可另設自己的 OAuth 設定。設定見 [雲端同步說明](docs/CLOUD_SYNC.md)。GitHub 不保存私人資料。

## 開發與發布

原生 HTML／CSS／ES modules，無建置步驟；main 推送自動以 GitHub Actions 發布 dist/，並更新 JS／CSS 快取版號。需要本機預覽時可用 Node.js 20+ 執行 npm start，但線上功能不依賴此服務。

目錄與維護指令見 [維護指南](docs/MAINTENANCE.md)。`dist/` 是網站原始碼與發布內容，不能當成建置暫存刪除。

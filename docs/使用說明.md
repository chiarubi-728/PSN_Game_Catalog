# 線上版使用

正式網站：https://chiarubi-728.github.io/PSN_Game_Catalog/

首次使用可從「匯入 JSON」匯入原本的完整備份。線上版與 localhost 的瀏覽器存檔分開；推送原始碼不會上傳個人遊戲資料。新網址的同步需要從本站更新兩支腳本至 0.2.3，已改為只信任自己的 Pages 與本機來源。

平台、完成狀態、來源、完成率區間與排序都可在線上使用。即時查詢官方中英文名稱仍需本機 Node 服務；可先在本機完成，再把包含 storeNames 的完整備份匯入線上版。Google Drive 另需把 https://chiarubi-728.github.io 加入 OAuth 允許來源。

# 完整遊戲庫：數位擁有＋全部遊玩紀錄

本次在原 PS Game Base 專案上新增完整遊玩紀錄，PSNProfiles 腳本版本為 **0.2.3**。Sony 數位遊戲庫腳本與本機助手繼續使用目前版本。

## 使用步驟

請在原本裝有 Tampermonkey 的 Chrome／Edge 操作：

1. 開啟 `http://localhost:4175/scripts/ps-game-base-psnprofiles.user.js`，安裝或更新同名腳本至 **0.2.3**。腳本在擴充功能中的舊名稱仍含「白金比對」，保留名稱是為了更新既有腳本；頁面面板會顯示「完整遊玩紀錄 v0.2.3」。
2. 回到 `http://localhost:4175/`，按 **Ctrl＋F5** 重新整理。
3. 按 **同步 PSNProfiles**，確認帳號為 `chiarubi`，再按 **開啟 PSNProfiles 並同步全部遊戲**。
4. 若來源網站出現安全驗證，正常完成驗證。腳本會展開全部公開遊戲，讀取平台、獎盃進度及白金狀態。
5. 面板顯示 **Game Base 已確認保存完整遊玩紀錄** 後，回到遊戲庫查看。

聊天內建瀏覽器沒有你一般瀏覽器中的 Tampermonkey 安裝；請使用上述已安裝擴充功能的瀏覽器。

## 會看到什麼

- **所有遊戲**：數位授權與遊玩紀錄的聯集。
- **數位擁有**：最近官方數位庫仍有授權的遊戲；沒有玩過也會保留。
- **玩過的遊戲**：PSNProfiles／Sony 有遊玩或獎盃紀錄的遊戲，包含 0% 進度。上方統計與白金使用相同主要來源，依來源遊戲 ID 去重，避免未合併的雙來源卡片重複增加統計。
- **白金**：只依來源已取得標記判斷。上方統計優先採 PSNProfiles 的獎盃清單 ID 計數，沒有 PSNProfiles 時採 Sony；不把兩個來源直接相加，也不計入個人白金分類。原本的個人白金標記保留，可用「僅有個人白金標記」篩選。
- **玩過・尚未白金**：已同步遊玩紀錄但沒有白金的遊戲，包含本身沒有白金獎盃的作品。
- **僅有遊玩紀錄**：沒有對應目前數位授權的遊玩紀錄。這包括實體版等來源；不能僅依獎盃推定目前仍持有實體片。

PS4、PS5 各自顯示。PS3／PS Vita／PC 若出現在公開紀錄，也會保留。共用獎盃清單的多平台遊戲保留來源的多平台標示，不推斷曾在哪一台主機玩過。

## 交叉篩選與排序

此次篩選更新只需回到原本的 `http://localhost:4175/` 按 **Ctrl＋F5**，不必重裝腳本或重新匯入資料。

- **平台**：PS5、PS4、PS3、PS Vita、PC。
- **完成狀態**：已白金、玩過尚未白金、100% 完成、未達 100%、已白金但未達 100%、已有獎盃／進度、0% 進度、尚無遊玩紀錄、進度不詳。
- **遊戲來源**：數位擁有、數位擁有且玩過、數位擁有但尚無遊玩紀錄、僅有遊玩紀錄、歷史數位授權。
- **更多篩選**：PS Plus 授權、PSNProfiles／Sony 資料來源、個人標記、自訂分類、完成率上下限。
- **排序**：名稱、完成率、已取得獎盃數、來源清單順序、最近整理。缺少完成率或獎盃數的項目排在最後；來源順序依已保存的 PSNProfiles 清單優先，其次為 Sony，並非最近遊玩日期。

全部條件取交集，也能搭配左側清單與中英文搜尋。例如選 **PS5＋玩過尚未白金＋完成率 50–99%**。條件以標籤顯示，可逐個移除，或按 **清除篩選** 回到所有遊戲。此分頁重新整理會保留條件。

白金與 100% 完成分別判定；沒有白金獎盃的遊戲也可能達到 100%。進度不詳不會當成 0%，設定完成率區間時會排除進度不詳的項目。「玩過尚未白金」也包含沒有白金獎盃的作品。個人白金標記在「更多篩選 → 個人整理」中獨立查詢。

上方統計維持全庫數字；清單上方顯示「符合條件卡片數／全部卡片數」，共用獎盃的多平台卡片可符合其中任一平台。

## 自動合併方式

### 批次取得官方中英文名稱

本機版重新整理後，只要已有數位授權與遊玩紀錄，就會開始以數位商品 ID 查詢 Sony 公開商店中的原名與作品名稱。上方「自動合併中英文遊戲」顯示進度，也可按「補齊中英文對照」重試未取得的項目，或按「停止查詢」保留已完成的部分。不必逐款輸入翻譯，也不需要重新安裝 PSNProfiles 腳本。

名稱來自同一個商品／作品的官方資料；僅清理平台與語言列表等商店標示，保留續作數字、重製版與版本名稱。自動合併仍要求相同平台與唯一候選；同名多個獎盃版本不會強行合併。已取得的官方名稱會加入搜尋與卡片的其他名稱，編輯遊戲可查看官方名稱對照。

資料由本機 `server.mjs` 的固定公開商店介面查詢，每批最多 4 個商品、同時最多 2 個 Sony 請求；不使用 Sony 登入憑證。查詢只送往 `store.playstation.com`。已取得名稱保存在此瀏覽器的 `storeNames`，完整備份與 Google Drive 備份一併保留；下次開啟會沿用。成功對照 30 天內不重抓，查不到的項目暫存一天以免反覆查詢，按補齊可立即重試。

商品下架、官方名稱本身不同或不同區域／獎盃版本仍可能無法唯一確認，這些紀錄會繼續完整顯示。來源白金數依 PSNProfiles 獎盃 ID 計算，卡片合併不改變白金統計。合併後原遊玩卡片的筆記保留在個人資料與備份；若與數位卡片筆記不同，編輯視窗會另外顯示原遊玩紀錄筆記。

此功能需要更新後的本機 Node 服務。GitHub Pages 只有靜態檔案，無法直接執行新增的本機查詢路由。

優先採 Sony 遊戲 ID → NPWR 獎盃 ID 對應，再以名稱、相同平台、已核對的中英文對照及既有名稱紀錄做唯一配對。不同區域、同名多個獎盃版本或證據不足的來源會獨立顯示，仍完整加入清單，不需要先手動配對。搜尋會包含已合併的中英文來源名稱。

PSNProfiles 更新頻率取決於來源網站；同步讀取的是該網站目前公開顯示的資料。白金只依已取得標記判斷，不以 100% 進度代替。

## 分頁沒有自動傳回時

1. 在 PSNProfiles 的腳本面板按 **匯出遊玩紀錄 JSON**。
2. 回遊戲庫的同步視窗，展開 **分頁無法傳回：JSON 匯入／匯出**。
3. 按 **匯入遊玩紀錄 JSON** 選取剛下載的檔案。一次匯入整份紀錄，不需要逐款選擇。

也可以直接在能正常開啟的 `https://psnprofiles.com/chiarubi` 分頁，按腳本面板的 **讀取全部遊戲**。Platform、Completion 要是 All，搜尋欄留白，才能取得完整資料。

## 資料與備份

數位授權仍存於原本的 `library`，個人整理仍在 `personal`；完整遊玩來源新增於 `history`。重新同步會依來源 ID 更新，不會重複新增相同 ID，先前同步過但來源這次未顯示的紀錄也保留。不同帳號的遊玩資料會拒絕合併。

「匯出完整備份」與 Google Drive 完整備份都包含 `history`。另可在同步視窗單獨匯出全部遊玩來源。舊版備份與舊白金 JSON 仍可匯入；舊白金檔不包含未白金遊戲，需執行一次新版完整同步。

本次完成語法檢查，未執行功能測試。真實公開頁面讀取與跨分頁回傳，需在使用者已安裝腳本的瀏覽器完成；直接背景抓取目前會受到來源網站 403／安全驗證限制。

## 讀取錯誤的診斷

v0.2.1 支援不同層級的平台標籤、未帶帳號與結尾斜線的獎盃連結。若某列仍無法辨識，面板會顯示遊戲名稱、列號與原因，並啟用「匯出讀取診斷」。診斷只含公開遊戲列的名稱、平台標籤、來源路徑與欄位文字，不含 Cookie、登入權杖或頁面網址參數。請提供該診斷 JSON，才能按實際結構修正；不會把缺漏的清單當作完整同步。

### v0.2.3：修正展開全部遊戲

使用者的真實診斷顯示，100 筆遊戲均可解析，唯一失敗列是 `Show 109 more games` 載入按鈕。此控制項使用 `a.title`，沒有舊程式預期的 `.load-more` 標記。已改為辨識這個按鈕並自動點擊，遊戲列計數會排除控制項；依「目前遊戲數＋剩餘遊戲數」檢查總數。這份診斷對應的完整清單預期為 209 款；未達預期數量不會傳回完整結果。

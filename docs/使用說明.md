# 線上遊戲庫使用說明

網站：https://chiarubi-728.github.io/PSN_Game_Catalog/

## 第一次使用

在同一個 Chrome／Edge 裝好 Tampermonkey，從「資料管理 → 首次設定／更新腳本」安裝／更新「PSN Game Catalog」至 **v0.3.1**。這一支已包含數位授權、PSNProfiles 完整遊玩紀錄及官方中英文名稱查詢。

停用舊的「PS Game Base 遊戲庫」、「PS Game Base 白金比對 · PSNProfiles」與獎盃助手腳本，避免同頁執行兩次。新版會要求在自己的網站執行，以及連線 Sony 公開商店的權限；更新後重新整理網站及來源分頁。

帳號預設 chiarubi，已匯入的帳號會沿用。需調整時在資料管理確認；不同帳號紀錄不自動混合。

## 日常只按「同步遊戲庫」

1. **數位授權**：開啟 Sony 官方遊戲庫，在該分頁登入並切到「已購買」。完整資料回傳後自動合併保存，不需再匯入或確認個人整理。
2. **遊玩與獎盃**：重用同一個來源分頁，自動切到 PSNProfiles，展開完整清單，讀取平台、白金、未白金與完成率。若出現來源網站驗證，請正常完成驗證。
3. **中英文名稱**：整合腳本在瀏覽器查詢固定的 Sony 公開商店商品資料，按原商品 ID／作品 ID 取得原名，再以相同平台與唯一候選自動合併。

進度視窗可收起，同步仍會繼續。關閉來源分頁、逾時或讀取失敗時，已保存的階段保留；按「重試未完成步驟」只從未完成的部分繼續。停止等待後不再接受該輪來源回傳，已保存的資料不撤回。

官方名稱每批最多 4 個商品、同時最多 2 個公開請求，不送登入 Cookie 或授權資料。已取得對照快取 30 天，查無資料暫存一天；限流時停止後續查詢。下架、不同區域或無法唯一確認的遊戲仍獨立保留，不把名稱查不到視為沒有遊戲或白金。

Sony 數位庫與 PSNProfiles 都依來源目前提供的資料讀取，無法強制更新 PSNProfiles 本身的紀錄。獎盃只證明曾玩過，不能證明仍持有實體片。共用獎盃清單的多平台作品保留原標示。

## 篩選

整個「篩選與排序」區塊可點標題展開／收起，預設收起。同一分頁重新整理會記住整塊與更多篩選的展開狀態。折疊只影響顯示，條件繼續生效；收起時標題仍顯示已套用條件數、是否已排序或區間錯誤提示。

側欄只保留白金、忽略、追蹤。點左上 GAME BASE 可回到所有遊戲，也可用「清除篩選」重設全部條件。

平台為 PS5、PS4、PS3、PS Vita，移除 PC 篩選；既有 PC 或共用多平台紀錄仍保存。完成狀態只留「已白金」、「未白金」（有遊玩紀錄但未取得白金）、「未 100%」（已知完成率低於 100%，包括 0%，不論白金與否）、「尚無遊玩進度」（沒有遊玩紀錄、0% 或進度不詳）。各項可重疊，預設為全部。

遊戲來源只留「數位擁有」及「非數位擁有（僅有遊玩紀錄）」，預設為全部。「更多篩選」移除數位授權及資料來源，保留個人整理、自訂分類與完成率範圍。例：PS5＋未白金＋完成率 50–99%。

進度不詳雖歸入「尚無遊玩進度」，其原值仍為未知，不會改寫成 0%；指定完成率範圍時仍會排除未知。以前匯入的 Sony 獎盃資料與未出現在同步的原始授權均保留，只移除相關入口。

條件可逐個移除或一鍵清除，重新整理此分頁會保留。上方數字為全庫統計，結果列顯示符合條件卡片數／全部卡片數。排序提供名稱、完成率、獎盃數、來源順序與最近整理；缺資料的數字放最後。來源順序不是最近遊玩日期。

## 批次加入分類

勾選遊戲後，工具列只保留「選擇分類」和「加入分類」。白金（個人標記）、忽略、追蹤與自己的分類列在同一個選單；沒有選擇分類時無法加入。加入後保留勾選，可接著加入其他自訂分類；不重複新增相同分類，筆記、標籤及其他自訂分類均保留。

白金為個人標記，不會修改來源獎盃與已取得白金統計。若需清除標記，仍可在遊戲編輯視窗處理。

## 資料管理

備份、JSON 匯入／匯出、單一來源重讀與診斷均收在資料管理。正常同步保留原分類、標籤與筆記；匯入個人整理或完整備份仍先顯示預覽，再由你確認是否取代。

網站資料保存在目前瀏覽器；同一網站重新整理可沿用。切換網址、瀏覽器或裝置前匯出完整備份。完整備份包含數位授權、個人整理、全部遊玩來源與名稱對照。GitHub 不保存這些私人資料。

Google Drive 是選用備份，與遊戲同步分開，需由 OAuth 管理者允許 https://chiarubi-728.github.io 來源。

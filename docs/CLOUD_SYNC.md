# Google 雲端自動同步（試用）

Google Drive 同步為選用功能。網站已提供公開 OAuth Client ID，直接按「Google 登入」即可授權自己的備份空間；不連接 Google 也可在瀏覽器整理及匯出 JSON。

雲端功能需要有效授權及專案的 Google Drive API 設定。網站發布不會變更 Google 品牌或網域審查狀態；實際狀態由擁有者在 Console 確認。跨裝置及衝突流程的驗收範圍見 [目前交接狀態](HANDOFF.md)。

## 使用流程

1. 原有正式網站的瀏覽器存檔沿用，使用雲端前仍可從資料管理匯出完整備份。
2. 主畫面按「Google 登入」並選擇自己的帳號；第一次載入 Google 授權尚未就緒時可能需再按一次。
3. 新裝置與朋友不需填 Client ID。若使用本機預覽，資料與正式網站分開，可先匯入備份。登入後的「雲端設定」可檢查狀態。
4. 連接後自動讀取雲端及儲存修改，等主畫面顯示「已同步至雲端」後離開。
5. 其他裝置使用同一應用程式、同一 Google 帳號，連接後自動載入。使用者已在兩邊各自修改時，先選擇要保留的整份版本。

## 網站擁有者與自架網站的 Google 設定

由專案擁有者在 Google Cloud 專案啟用 Google Drive API、設定 OAuth 同意畫面，並建立類型為「網頁應用程式」的 OAuth Client ID。將正式來源 https://chiarubi-728.github.io 加入 Authorized JavaScript origins。本機預覽使用的來源也需另行加入，例如 http://localhost:4180。OAuth 應用程式仍在測試狀態時，需將使用者加入測試名單。

網站直接使用 `dist/cloud-sync.js` 的 `DEFAULT_CLIENT`，介面不顯示 Client ID，也不提供自訂授權設定。一般使用者只需使用 Google 登入並查看同步狀態；「復原備份」仍可匯出版本切換前的資料。自架網站由維護者修改原始碼中的公開 Client ID，不需要也不應加入 Client Secret。

2026-10-23 依擁有者提供的新設定更換內建 Client ID（專案號碼開頭為 `381225452249`）。更新後重新整理遊戲庫，再連接 Google。原本機存檔及舊同步基準保留；跨應用程式比對仍會要求確認版本，未新增自動搬移雲端資料的流程。若出現版本選擇，先確認帳號與兩份內容，再決定使用哪一份；不要為了換 ID 清除網站資料。

舊版瀏覽器曾保存的自訂 Client ID 不再覆寫網站設定；既有同步基準仍保留 OAuth 應用程式識別。若先前使用其他應用程式，連接時沿用既有版本衝突保護，不直接上傳非空白本機資料。更換 OAuth 應用程式／Google Cloud 專案可能切換 Drive 的應用程式資料空間，需透過完整備份搬移；不要假設更換後仍能讀到原應用程式的備份。

要求的權限只有 Drive 應用程式資料、Google 帳號 ID 與電子郵件。權杖只在記憶體，不寫入 localStorage、備份或 Git。Google sub 與 OAuth 應用程式用來辨識同步基準，避免連接另一個帳號後直接上傳。

## 同步及保護

- 修改先存本機，約 1.4 秒後排隊上傳；請求串行，連續修改只上傳最新完整快照。
- 每次寫入前讀取雲端版本，以最後成功同步的 SHA-256 基準分辨本機修改與雲端修改。只一邊修改就自動套用；兩邊修改則暫停選擇，不以較晚時間盲目覆蓋。
- 以 Drive 版本及 If-Match ETag 保護寫入。檔案清單、下載與首次建立沿用 v3；版本保護碼從 v2 檔案 JSON 的 etag 取得，更新既有檔案也使用 v2，避免依賴瀏覽器能否讀取 v3 的 ETag 標頭，且不混用內容與中繼資料的 ETag。下載前後核對版本與保護碼；無法取得就停止寫入，不退回無保護的覆蓋。上傳後讀回確認，再顯示已同步。首次同時建立造成重複檔案時也暫停，不自動刪除任一份。
- 資料未改變時，輪詢只讀清單版本並沿用已驗證快取。切回視窗、上線後，以及前景每 30 秒檢查一次。已同步且無本機修改時，背景檢查保留「已同步」狀態與時間，不反覆顯示同步中或重寫同步基準；真正上傳／載入資料、版本衝突與錯誤才更新狀態。首次連接、手動立即同步與尚未完成的修改仍顯示處理進度。網路錯誤最多延遲重試四次，之後可手動立即同步。
- 正在編輯遊戲、管理分類、預覽匯入或等待遊戲來源時，暫緩套用雲端資料。讀取期間若本機又有修改，重新比較；上傳期間新增的修改接續排隊。
- 版本選擇前先將兩份快照寫入本機復原儲存區。空間不足則停止選擇；可先匯出雙方版本。復原匯出檔與既有完整備份格式相同。
- 其他分頁已修改、原本機存檔載入失敗或儲存失敗時，暫停雲端同步；不拿空白狀態覆蓋雲端。讀檔失敗也鎖定所有本機寫入，提供原始存檔下載與完整備份復原。示範模式不讀寫雲端。
- 完整快照包含使用者確認的 PSN 帳號、平台／來源識別關係、手動卡片配對／保持分開設定及個人標記修改時間。帳號設定也視為本機資料，首次雲端比對不會將已設定帳號當成可直接丟棄的空白狀態。快照內 Sony 與遊玩帳號不一致時拒絕載入；跨版本的整份選擇規則不變。
- 資料仍有 5 MB 雲端上限。此版本需要頁面開啟及有效授權，不是背景服務；授權過期／重開網站可能需再次連接。新裝置永遠只能取得最後成功上傳的版本。

## 更新前本機備份

網站會在讀取及雲端操作前保存更新前的原始存檔（僅保存一次，不覆寫舊備份）。從資料管理「匯出更新前備份」可下載。備份仍在此瀏覽器，清除網站資料會一併清除；如瀏覽器空間不足導致備份失敗，雲端同步會先暫停，請先按「匯出完整備份」並確認檔案已保存。

OAuth 仍在測試模式時，朋友需先由網站擁有者將其 Google 帳號加入測試使用者名單。共用 Client ID 只識別網站，不會共用 Google 登入身分；雲端存取使用各自記憶體中的授權權杖。

## 對外發布 OAuth 應用程式

Google「品牌」頁須先完成應用程式名稱、使用者支援電子郵件、首頁與隱私權政策等欄位，才能在「目標對象」發布應用程式。此專案已提供公開且不需登入的政策頁，首頁及雲端設定均有隱私連結：

- 應用程式名稱：`PSN Game Catalog`。
- 使用者支援電子郵件：在主控台選擇擁有者持續收信的帳號，未將私人信箱硬寫入網站。
- 應用程式首頁：`https://chiarubi-728.github.io/`（公開首頁，另由 `chiarubi-728.github.io` 儲存庫維護；原 `PSN_Game_Catalog/about.html` 仍保留）。
- 隱私權政策：`https://chiarubi-728.github.io/privacy.html`。
- 服務條款／說明：`https://chiarubi-728.github.io/terms.html`。

以上兩個總站政策頁完整收錄 PSN Game Catalog 專屬內容，原 PSN_Game_Catalog/privacy.html 與 terms.html 繼續保留。首頁、遊戲庫及介紹頁的主要政策連結已改為總站網址；Google Console 的政策欄位需由擁有者更新。

政策依目前實作說明 Google 身分、Drive appDataFolder、瀏覽器保存、復原副本、權杖記憶體保存及刪除方式。修改資料處理方式時需同步更新政策。網站部署不會代為改變 Google Cloud 的首頁設定、發布或驗證狀態；如主控台另要求品牌、網域或資料存取驗證，依其實際要求完成。公開首頁沿用同一網域現有介紹頁的 Search Console 驗證 meta；仍須由專案擁有者確認其所有權驗證結果。
